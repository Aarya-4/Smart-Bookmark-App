 About This Project

This is a Smart Bookmark App built using Next.js and Supabase.

Users can log in with Google, save bookmarks, and manage them easily.

 Authentication & Privacy

Authentication is handled using Google OAuth through Supabase.
User sessions are stored securely.

Each bookmark is connected to a specific user, and database security rules make sure users can only see and manage their own bookmarks.

 Real-Time Updates

The app supports real-time updates.
When a bookmark is added, edited, or deleted, the changes appear instantly without refreshing the page.

Tech Used

Next.js

Supabase

Google OAuth

The main focus of this project was to build a secure, clean, and responsive full-stack application.
